# V2 可用率监控

V2 真实流量监控使用 Relay Pulse 风格的卡片/列表。V1 主动探测、配额监控及系统默认模式不变，不需要部署 Relay Pulse 服务。

## 使用

- 用户端：`/monitor`，系统模式为 V2 时展示新界面。
- 管理端：`/admin/channels/monitor`，V2 模式下默认进入「可用率监控」；「V2 数据监控配置」及 V1 标签保留。嵌入的监控页不读写地址栏参数，筛选状态不随刷新保留。
- 默认窗口为 24 小时，可选 90 分钟、7 天、30 天。
- 支持按平台、平台/分组、平台/模型、平台/分组/模型查看，以及卡片、列表、原色块矩阵和折线图。
- 平台筛选支持多选；卡片/列表顶部的「总体状态」栏提供搜索（含展开子项）、异常优先/名称/可用率排序、只看异常和全部展开。
- 展开后每个子项（模型或分组）显示可用率、平均首字延迟和迷你状态条；子项按异常优先排序，「其他模型」排在最后。列表视图的子项与主行共用列，数值上下对齐。
- 错误原因分「计入可用率」「已忽略」两栏，条形按当前列表最大占比等比缩放，数字仍是绝对占比；样本消息只对管理员显示。

## 添加 DeepSeek 等供应商

V2 的早期数据库默认配置只启用了六个平台。采集器支持其他平台，但未配置或未启用的平台不会被监控查询返回。

1. 在「V2 数据监控配置」→「平台与模型」中单独添加 DeepSeek，或点击「一键补齐供应商」。
2. 确认所需平台已启用；模型列表留空表示展示所有真实模型名。
3. 保存配置。供应商存在可见分组和真实流量后即可在监控页查看；无流量或样本不足显示灰色，不显示虚构的 100%。

补齐操作只添加统一平台目录中缺少的条目，**不重新启用已有禁用平台、不覆盖模型名单或分组范围**，保存前不会改变服务端配置。没有修改历史迁移或静默扩大展示范围。

## 数据契约与维护注意事项

- 新界面复用 `GET /[admin/]channel-monitor-v2/{snapshot,matrix,dimensions,errors}`，没有新增 API 或数据库字段。
- `matrix?group_by=platform_group` 等服务端聚合行提供卡片主指标；另取 `platform_group_model` 子行用于展开。平台汇总的子项使用 `platform_model`。
- 可用率为 `1 - metrics.error_rate`，但只有 `health.error_rate !== 'unknown'` 才显示数值。不能按前端 `request_count` 判断是否有数据：用户端请求量可能已被脱敏为零。
- **不对模型百分比求平均**；使用服务端计入请求加权的窗口结果。窗口可用率按现有 V2 口径计算，不改成 Relay Pulse 的「仅累加样本达标桶」口径。
- 卡片及时间条按 `health.error_rate` 着色，不使用包含缓存/延迟的综合评分。平均首字延迟使用 `ttft.avg_ms`，按同一阈值中的 TTFT 预算独立着色，而非把 P50 的评分标在 AVG 上。
- 时间条覆盖 `[coverage.requested_start, coverage.requested_end)`；历史未覆盖、无流量、样本不足为灰色。缺少 `requested_end` 的旧响应回退 `data_through`。
- 主时间条是一个 Tab 停留点，方向键 / Home / End 切换格子，悬停或聚焦时以浮层显示明细，不改变卡片高度；子项迷你条不可聚焦，只提供原生 title。
- 搜索/只看异常是卡片展示过滤；顶部 KPI、「总体状态」计数和错误分类仍基于平台/分组/模型 API 筛选范围。
- 自动刷新和切换筛选期间保留旧卡片并淡化显示；仅手动点击刷新时显示骨架屏。
- 供应商名称与选项来自统一平台目录；未知平台保留原名称并使用中性色，不在组件内维护另一份固定名单。
- 快速切换筛选和明细标签时，过期响应不得覆盖当前状态；离开页面取消未完成请求，隐藏标签页暂停轮询。

## 验证

相关测试位于 `frontend/src/features/channel-monitor-v2/__tests__/AvailabilityBoard.spec.ts`、`MonitorSettingsPanel.spec.ts`、`frontend/src/views/user/__tests__/ChannelStatusV2View.availability.spec.ts`，覆盖：

- 脱敏请求量仍能显示真实可用率、样本不足不显示 100%。
- 汇总不平均子项百分比，DeepSeek 及未知供应商展示、跨平台子项隔离。
- 状态时间条补空、键盘提示与方向键切换、子项迷你条、卡片/列表、搜索、排序及只看异常。
- 子项按父行未展示的维度命名，「其他模型」排在最后。
- 错误样本权限与忽略分类。
- 补齐供应商保留已有禁用状态、模型及分组配置。
- 用户/管理员 API 分流、筛选请求竞争，以及原 V1 模式与刷新行为。
